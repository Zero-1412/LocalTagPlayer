## L3 播放器与资源稳定性

### 双后端稳定性矩阵：失败/阻塞

MediaKit 首次媒体打开成功，首帧约 103 ms，硬解 `d3d11va-copy`，错误事件和失败打开数为 0；但 30 分钟长播没有在测试代码声明的 40 分钟超时内完成，测试最终报 `TimeoutException`。手工采样显示 working set 从媒体打开阶段约 485 MB 持续增长到约 1.02 GB，private memory 约达到 1.22 GB，说明存在需要定位的资源增长/释放问题。

脚本随后进入 MPV 后端，但启动诊断显示 `backend=unsupported`，没有形成可用稳定性报告；为避免在已明确失败的矩阵上继续无界等待，测试进程被停止。`player-backend-stability-matrix.json` 未生成，不能把此项判为通过。

证据：`backend-stability-run.log`、`backend-stability/mediaKit/`、`backend-stability/mpv/`。

### 十轮增删、缩略图与释放尾部：失败/未执行

隔离 profile + 真实只读媒体根启动后，在第 0 轮等待目标 UI 超时；`cyclesAdded=0`、`cyclesRemoved=0`，释放尾部样本为 0。零值不是性能通过数据，根因需要先定位媒体库 hydration/可播放入口前置条件。

证据：`library-add-remove/stress.log`、`library-add-remove/summary.json`。

### 真实库播放器长跑：失败/未完成

- 固定真实样本重试：15 秒内未进入可见结果，未进入播放循环。
- 去掉固定样本后的随机重试：成功进入播放器并完成第 1 轮打开、队列滚动、第一次 seek 和全屏往返入口；随后超过 2 分钟没有进入第二次 seek，测试进程被停止。过程日志同时出现大量 Flutter Windows `accessibility_bridge.cc` 的 `AXTree` 更新错误。
- 该轮进程指标在播放器阶段中位 working set 约 660.8 MB，线程中位数约 295；因全屏状态机未返回，不能外推 30 分钟趋势。

证据：`player-real-library/stress.log`、`player-real-library-retry/stress.log`、`player-real-library-retry/process-metrics.csv`、`player-real-library-retry/stress-00m-start.png`。
