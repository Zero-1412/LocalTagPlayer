
本次更新

- 全面统一媒体库、播放器、标签中心、设置和维护页面的深色工作区外壳，复用统一的圆角、间距、交互反馈、焦点和无障碍标准，减少重复创建的 UI 入口。
- 主界面功能栏首次默认折叠，并记住用户上次展开或折叠的状态；媒体库筛选、搜索、排序和结果视图在不同窗口宽度下保持一致的控件高度与可达性。
- 播放器启动决策、媒体控制、信息诊断、文件动作和上下文菜单统一深色浮层与反馈；设置、标签中心、缓存诊断、目录管理、缺失与重新关联和相似视频页面统一工作区层级。
- 维护页反馈、路径提示和危险动作确认保持清晰的状态反馈；播放器队列、来源筛选和视频卡片继续保留原有入口与交互边界。

数据安全

- 本次更新不改变既有标签、筛选条件、来源播放队列、收藏、播放记录或观看进度；folder 标签与 manual 标签来源继续分离。
- 安装包升级不会主动删除本地媒体库索引、标签、收藏、播放记录或缓存；如需回退，请先备份应用数据目录。

安装包说明

- 本次发布提供 Windows x64 安装程序与 macOS DMG；签名或公证状态以发布页中的实际资产说明为准。
- 发布页同时提供每个安装包的 SHA-256 校验文件，下载后可先核对校验值。
