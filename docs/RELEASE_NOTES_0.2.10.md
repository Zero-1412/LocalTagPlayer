本次更新

- 播放器媒体控制面板保留音轨、字幕、音画同步和章节操作，并在当前后端支持时提供逐帧、A-B loop 与外挂字幕入口。
- 进度定位和精确控制继续限定在当前播放会话；播放器返回媒体库时保留来源筛选状态，操作不改变标签、播放队列或用户记录。
- 播放器诊断补充输入链、Texture 呈现和资源释放的分层状态，遇到自动化环境缺证时明确显示未知或失败，不把缺证写成通过。
- 发布流程补齐可审查的版本索引、纯文本更新说明和安装包校验文件，便于升级后核对版本与资产。

数据安全

- 本次更新不改变既有标签、筛选条件、来源播放队列、收藏、播放记录或观看进度；folder 标签与 manual 标签来源继续分离。
- 安装包升级不会主动删除本地媒体库索引、标签、收藏、播放记录或缓存；如需回退，请先备份应用数据目录。

安装包说明

- 本次发布提供 Windows x64 安装程序与 macOS DMG；签名或公证状态以发布页中的实际资产说明为准。
- 发布页同时提供每个安装包的 SHA-256 校验文件，下载后可先核对校验值。
