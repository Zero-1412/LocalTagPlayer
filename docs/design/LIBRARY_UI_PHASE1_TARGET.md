# 媒体库首页 Phase 1 · Before / After 视觉目标

> 目标：把媒体库首页收敛为平静、精确、内容优先的桌面媒体工作区。
> 本阶段只改表现层和组件编排，不改变筛选、排序、播放队列、缩略图或用户数据。

## 受保护行为

以下行为属于本阶段的不可回归边界：

- 唯一真实 `TextField`、`TextEditingController`、`FocusNode` 和 `Ctrl+K` 聚焦链路；
- 不同标签组 AND、同组 OR、排除标签 NOT、关键词搜索和当前筛选 chips；
- 结果数量、扫描/导入进度、暂停/继续和取消入口；
- 排序字段、排序方向、网格/列表切换和多选工具栏；
- expanded 标签发现面板、medium/compact 筛选 sheet 以及一级/二级标签父级语境；
- 视频卡片 hover 预览、收藏、更多菜单、打开文件、删除确认和打开播放器；
- 增量加载、稳定 `videoId`、滚动位置、缩略图 Future 和来源 filtered queue。

## Before · 当前页面

| 区域 | 当前表现 | 用户成本 |
| --- | --- | --- |
| 左侧导航 | 导航、资料库维护、统计和路径入口集中在同一深色侧栏，选中态有较大紫色底色。 | 导航信息完整，但视觉重量偏高，容易与中心内容争夺焦点。 |
| 顶部上下文 | 标题/结果数、搜索/排序/视图、活动筛选分成多层，宽屏与中小屏有不同编排。 | 信息齐全，但“当前在哪、正在筛选什么、下一步做什么”需要在多个区域之间扫描。 |
| 标签发现 | 右侧大块圆角面板包含标题、一级/二级切换、说明和分组卡片。 | 标签能力强，但面板外壳和内部卡片层级较多，筛选状态和标签维护容易混在一起。 |
| 视频结果 | 卡片以圆角、边框和 hover 阴影建立层级，缩略图是主体。 | 结果浏览已经稳定，但静态态仍有较多结构线，文件名和结果数量的主次可以更明确。 |
| 响应式 | expanded 使用常驻左右结构，medium/compact 使用紧凑顶栏和筛选入口。 | 结构已经覆盖桌面窗口变化，但各断点的“同一工作区”连续感仍可加强。 |

│ 标签中心     │ 视频网格 / 列表                               │               │
│              │ 缩略图 > 文件名 > 状态                         │               │

| 区域 | 精确目标 | 验收判断 |
| --- | --- | --- |
| 左侧导航 | 保留所有入口和折叠能力；降低非选中项对比度，选中态只表达当前来源，不使用大面积装饰。 | 进入媒体库、继续观看、收藏、标签中心、目录管理、设置和折叠/展开均可达。 |
| 当前上下文 | 让页面标题、结果数量、标签面板入口形成第一层；搜索和高频动作形成第二层；活动筛选只在存在时出现。 | 静止态一眼回答“当前视图、结果多少、正在筛选什么”。 |
| 搜索 | 保留现有真实输入链路，使用稳定的独立搜索表面；不把筛选状态塞进输入框。 | `Ctrl+K`、键盘输入、清除、文字缩放和焦点语义保持。 |
| 标签 inspector | 面板是可展开的发现工具，不是业务状态副本；一级/二级关系、数量、排除态和父级语境清晰。 | 点击标签先看到结果变化；计数和缩略图任务不进入动画关键路径。 |
| 视频结果 | 缩略图、文件名和当前状态是主视觉；卡片边界弱化，hover/焦点只提供反馈和必要动作。 | 网格列数、卡片 key、缩略图 Future、滚动锚点和打开播放器行为不变。 |
| 响应式 | expanded 保留深度工作区；medium 折叠标签 inspector；compact 使用明确筛选 sheet。 | 由窗口宽度决定布局，125%/150% 文字缩放不裁切、不溢出、不隐藏关键动作。 |

## 视觉规则

- 画布使用稳定深色；结构侧栏和 inspector 使用实色；不新增全窗口 blur。
- 紫色只表达选中、焦点和主要筛选动作；不把整条工具栏铺成强调色。
- 普通控件命中区保持至少 40px，关键桌面动作优先 44–48px。
- 继续使用现有 `AppRadius`、`AppSpacing`、`AppMotion` 和 `AppAccessibilityScope`，不创建平行 token。
- 普通搜索、标签点击、排序和列表导航不等待装饰动画；reduced motion 只保留短淡入和颜色反馈。
- 100%/125%/150% 文字缩放、high contrast、键盘焦点和 tooltip 都属于完成条件。

## 本阶段实现顺序

1. 页面外壳：媒体库画布、左侧导航和 expanded 三栏间距。
2. 上下文栏：标题/结果状态、搜索/动作带、活动筛选。
3. 标签 inspector：标题、模式切换、搜索和分组表面。
4. 视频结果：卡片边界、缩略图叠层和标题信息密度。
5. focused tests、完整静态验证、Windows debug build 和真实窗口截图。

## 明确不做

本阶段不修改 SQLite schema、`FilterQuery`、`TagQueryService`、`PlayerBackend`、
filtered queue、thumbnail/media-details queue、stable identity、扫描规则、标签层级
语义或任何用户数据持久化行为。
