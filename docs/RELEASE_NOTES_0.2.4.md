本次更新

- 加快应用内安装包下载。支持并行分段下载、实时速度与预计剩余时间，并可复用已经
  下载且校验通过的同版本安装包。
- Windows 安装器界面统一使用简体中文，安装、覆盖、关闭应用、完成和卸载过程不再
  混用英文提示。
- 改善连续和长按快进、快退的画面跟随。首次操作立即响应，持续按住时会稳定更新画面，
  松开前的最终位置也不会丢失。
- 视频画面支持双击切换播放与暂停；播放器主界面支持按回车键进入或退出全屏，长按不会
  导致状态反复切换。
- 播放、暂停、音量、全屏、切换视频和快进快退提示统一显示在视频左上角，中央不再遮挡
  内容；提示改为半透明背景和高亮文字、图标。
- 修复 Windows Debug 构建可能被测试入口覆盖后无法双击启动的问题，并增加正式构建后的
  可见窗口启动门禁。

数据安全

- 本次更新不改变标签、筛选结果播放队列、收藏、播放记录或播放进度。
- 安装和升级不会删除现有媒体库数据库及用户整理的数据。

安装包说明

- Windows x64 安装包当前未进行 Authenticode 签名。
- macOS DMG 当前未进行 Developer ID 签名或 Apple 公证。
- 下载后可使用随附的 SHA256SUMS 文件核对安装包完整性。
