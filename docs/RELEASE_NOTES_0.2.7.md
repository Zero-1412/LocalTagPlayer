本次更新

- 修复标签编辑器在中文输入法确认候选词时，输入内容可能被清空或被提前作为标签添加的问题。
- 优化标签输入框的 Enter 键交互：确认候选词后保留文本，再次按 Enter 才会正常添加标签。
- 保持标签编辑器既有的 Ctrl+Enter 保存、Tab 浏览候选和 Esc 取消操作，避免快捷键相互干扰。

数据安全

- 本次更新不改变既有标签、筛选条件、收藏、播放记录或观看进度。
- 安装包升级不会主动删除本地媒体库索引和用户数据；如需回退，请先备份应用数据目录。

安装包说明

- Windows 安装程序当前未进行 Authenticode 代码签名；首次运行时如出现系统提示，请确认发布来源为本项目的 GitHub Release。
- macOS DMG 当前未使用 Developer ID 签名或公证；如系统拦截，请在确认来源后按系统提示允许打开。
- 发布页同时提供每个安装包的 SHA-256 校验文件，下载后可先核对校验值。
