本次更新

- 修复小窗口播放器控制条溢出。窗口宽度低于 900 dp 时会使用紧凑布局，文件定位、
  音量、播放控制、截图、设置、全屏和播放队列等功能仍然完整保留。
- 调整播放队列展开位置。小窗口下队列现在从播放器右侧展开，不再显示在位置不符的
  居中弹层；同时移除了顶部重复的队列按钮。
- 首次启动默认窗口调整为 1600×900，让播放器功能和右侧队列更容易完整显示。
  已经保存过窗口尺寸的用户不会被覆盖。
- 优化低画质视频缩小播放。播放器会根据实际显示区域选择更合适、更稳定的输出尺寸，
  减少无意义的显存占用和快速缩放时的画面重建。
- 提升连续切换视频、拖动进度和快速缩放时的播放稳定性，减少播放器属性互相覆盖或
  迟到任务影响当前视频的情况。
- 完成播放器画质参数实测。没有把看不出画质收益、却会增加资源占用的缩放参数设为
  默认值。

数据安全

- 本次更新不改变标签、筛选结果播放队列、收藏、播放记录或播放进度。
- 安装和升级不会删除现有媒体库数据库及用户整理的数据。

安装包说明

- Windows x64 安装包当前未进行 Authenticode 签名。
- macOS DMG 当前未进行 Developer ID 签名或 Apple 公证。
- 下载后可使用随附的 SHA256SUMS 文件核对安装包完整性。
