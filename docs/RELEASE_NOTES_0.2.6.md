本次更新

- 新增音轨、字幕与章节控制：可切换内嵌音轨和字幕、关闭字幕，并调整字幕与音频延迟。
- 改善快进和快退后的恢复体验：短按与长按会减少重复跳转，播放位置和声音恢复更稳定。
- 新增不冲突的播放器快捷键，用于音轨、字幕和同步调整；原有快进、快退和队列快捷键保持不变。

数据安全

- 本次更新不改变标签、筛选结果播放队列、收藏、播放记录或播放进度。
- 安装和升级不会删除现有媒体库数据库及用户整理的数据。

安装包说明

- Windows 安装器未进行 Authenticode 签名。
- macOS DMG 未进行 Developer ID 签名或 Apple 公证。
- 下载后可使用随附的 SHA256SUMS 文件核对安装包完整性。
