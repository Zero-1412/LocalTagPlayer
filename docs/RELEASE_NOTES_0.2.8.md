
本次更新

- 缓存诊断页新增“生成缺失缓存”入口；媒体库首帧后会错峰登记安全的缩略图和媒体详情补全任务，也可以按需手动开始。
- 缩略图和媒体详情补全改为有界、可持续推进的后台任务，超过 500 项的候选不会被截断；播放期间让位并继续保持可视内容优先。
- 重新整理启动后台任务的资源预算和取消边界，备份续跑与缓存补全可自动执行，新视频扫描、无效记录清理和视觉相似度扫描仍保留原有确认或设置门禁。
- 已知媒体详情失败项不会在每次启动时无限重试，仍可从诊断页显式重试；缓存生成失败、清理和重试状态更容易复核。

数据安全

- 本次更新不改变既有标签、筛选条件、来源播放队列、收藏、播放记录或观看进度；folder 标签与 manual 标签来源继续分离。
- 安装包升级不会主动删除本地媒体库索引、标签、收藏、播放记录或缓存；如需回退，请先备份应用数据目录。

安装包说明

- Windows 安装程序当前未进行 Authenticode 代码签名；首次运行时如出现系统提示，请确认发布来源为本项目的 GitHub Release。
- macOS DMG 当前未使用 Developer ID 签名或公证；如系统拦截，请在确认来源后按系统提示允许打开。
- 发布页同时提供每个安装包的 SHA-256 校验文件，下载后可先核对校验值。
